What it does

Everything in one pipeline

🌐

URL Input

Enter any public URL on the Task page. The app validates and passes it to the scraping engine instantly.

🔍

Smart Scraping

Uses Requests + BeautifulSoup to extract titles, headings, paragraphs, links, and metadata.

💾

Auto Save

All scraped results are saved as timestamped JSON files in the scraped_data/ directory.

📧

Email Delivery

The report is automatically emailed to every group member with the JSON file attached via Gmail SMTP.

⏰

Scheduled Jobs

The schedule library triggers the scraper every morning at 08:00 AM in a background thread.

⚡

Live Feedback

The Task page shows real-time results: scraped data summary displayed directly in the browser after submission.
